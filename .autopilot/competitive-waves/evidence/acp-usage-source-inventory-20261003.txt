Next design/build acceptance to preserve

1. Host physical TurnId durably recorded and awaited BEFORE each actual RPC,
   including initial and feedback dispatch (stage/agent.rs:1297,1333). Bind run,
   node occurrence, host/provider session identity, opening occurrence and source
   contract/version. Resume/wake creates new physical turns even for equal text.
2. Carry turn identity through bridge commands and return typed completion
   receipts. Broadcast delivery cannot be the only reliable path (worker.rs:87
   ignores send failure); lifecycle.rs:168-170 may drop the completion future.
3. A dedicated run-writer transaction inserts a receipt under unique(turn,source),
   compares exact replay, rejects conflicting replay atomically, computes only
   contracted deltas, updates baseline/coverage, and appends accounting event/view
   changes together. Registry paging must conserve these normalized deltas.
4. Keep independent u64 buckets and reported total, nullable model/currency.
   SQLite INTEGER cannot losslessly store every u64: specify representation and
   checked aggregate overflow. No guessed subset sum or price estimate.
5. Loaded cumulative sessions require a trusted prior baseline. Missing usage,
   failed/cancelled/unobserved turns, counter decline, contract/version changes
   and unknown semantics preserve incomplete coverage. Token coverage and pricing
   coverage must remain separate; usage_seq > 0 does not prove completeness.
6. Keep legacy TokensConsumed decoding/meaning and existing hashed JSON bytes.
   Add versioned accounting variants/receipt hashes; do not rewrite historical
   append-only blobs. Current event schema version is 14. Requirements hash uses
   serde_json::to_vec, so new defaults in old hashed structures require goldens.
7. Triage/project-context prompt callers need an explicit accounting scope, not
   silently complete task-ledger coverage.
