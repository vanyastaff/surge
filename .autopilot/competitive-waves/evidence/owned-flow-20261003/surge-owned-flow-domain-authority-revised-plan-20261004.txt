1. Property and trust boundary

Required property: before suspension/Continue/wake/new same-workspace dispatch, ALL
registered writers and outstanding protocol-defined operations of the prior epoch
must have original host-issued terminal evidence, including obligations reserved
without journal intent. Completed effects are not undone. This is not universal
provider/account quiescence and does not assert all causally related remote
computation has stopped. A supported adapter must define the exact operation it
settles; unmediated async work remains Unknown unless its real implementation or
broker boundary supplies the required contract.

ADR0014 explicitly delegates deeper sandbox enforcement, requires configured
trusted binaries in unconstrained MCP modes, and is not a hostile-process syscall
sandbox. Malicious configured same-UID processes modifying SQLite/private keys/
locks, tracing/signaling the host or forging trusted storage are OUTSIDE this
existing threat boundary. 0600, HMAC and opaque Rust types do not prevent that
attack. Extending the threat model would require a separate credential/filesystem/
broker product decision, not a hidden requirement in this amendment. Accidental
cancellation, crash, descendant escape by setsid, lost observations, asynchronous
operations, and untrusted protocol data ARE inside the correctness scope.

No trust checkbox, protocol success, EOF, direct leader exit, empty process group,
SessionClosed or cleanup_confirmed bool creates native/external authority. Existing
GroupOnly empty remains Unknown. Native closure concerns actual local membership;
external responsibility is distinct. Current local_effects:false MCP records cannot
be retroactively relabeled local-only. Legacy journals remain readable but unknown
owned closure does not permit continuation. Accepted IDs, raw prompts, graph,
private inputs, frozen selection, workspace and original startup stay unchanged.

real held child and zero target instructions; settle/reap it, NEVER NoChild. Stop
AFTER Release: executed original domain must close. Unconsumed Release proves only
no release, not no child. No-process OS error may create NoChild only when backend
error contract proves create returned no child. Created-but-unobserved is Unknown.
