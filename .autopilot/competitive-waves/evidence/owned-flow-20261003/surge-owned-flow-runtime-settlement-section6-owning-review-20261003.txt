Required final amendment:
1. Sender::send consumes its message by value. The plan says parcel remains
   outside catch while protecting transfer but specifies no mechanism making
   that true; moving sole parcel into send can drop it during unwind before catch.
   Specify transfer of an Arc clone to an outer retained ownership slot containing
   Option<ChildParcel>, rather than transfer of sole raw parcel. Caller retains
   slot outside catch until handoff; worker claims parcel under a defined protocol.
   During failure/unwind the actual parcel must remain in outer slot or already
   be exclusively worker-owned, never owned only by an unwinding message. Alternatively
   provide pinned primary-source proof for a closed non-unwinding sender, including
   every admitted private injection path. The outer retained-slot approach is
   easier to audit and protects deliberate send-panic injection. Once this is
   explicit the rest of the design is acceptable for implementation.

Other implementation audit points implied by the plan:
2. Fallback worker must not signal its own reservation completion before dropping
   retained observer. Barrier must not miss pending/fallback registrations or
   handles taken for another reservation's finished-thread reaping. No global
   mutex held across join, child operation, observer Drop, or fatal callback.
3. Protect diagnostics and teardown operations that could panic while a live
   parcel exists. A success-path guard restoring TLS depth must not restore it
   on unwind before catch sees panic; retained panic payload must never be dropped.
   Installing OnceLock dispatcher before reservation must complete atomically for
   concurrent first callers. Normal host hook installation order is audited in
   actual CLI/daemon/UI entrypoints, not asserted only in documentation.
4. Terminal guard must implement runtime-before-barrier on unwind and ordinary
   return; UI enter guard lifetime ordered ahead of runtime destruction. Helper
   branch must preserve special background policy under both normal and unwind
   paths. No remaining process::exit bypass or cached-transport dependency.
5. The tracker is process-terminal and permanently closed after barrier. Tests
   requiring fresh admission must isolate processes/private test tracker scopes;
   production API must never silently reopen admission to make tests pass.

Performance/API assessment: bounded worker-per-child admission is defensible for
this local host profile. The 128x512KiB stack allocation upper bound is roughly
64MiB of requested stacks, plus OS overhead; bounded refusal is safer than owner
eviction. Completion handle reaping keeps reconnect history bounded. Grace runs
concurrently under normal worker shutdown; synchronous post-spawn fallback may
block a caller indefinitely after wait ambiguity, an explicit accepted outcome.
The public shutdown barrier is terminal and blocking; callers must invoke after
runtime shutdown, never from a worker or while holding ownership/tracker locks.
