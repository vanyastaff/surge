WHY THE BOUNDED CHANGE IS SOUND

1. Exact current defect: connection.rs:339–346 maps before_child failure into
   StartFailed. ensure_connected:292–333 then consumes restart history and changes
   ConnState even though Surge's physical spawn path has not been entered. Existing
   EffectRefused has a separate no-state-mutation branch. The same preservation
   branch for WriterOwnershipRefused is coherent and does not change restart
   decisions for real spawn/handshake failures.

2. Callback-boundary classification is appropriate. before_child is an untyped
   WriterObservationError prerequisite; actual engine observer calls an early host
   control check inside it before journaling. Therefore the new error MUST mean
   that callback refused/failed, not proof of specifically SQLite failure. The
   finalcallbackprecision paragraph correctly avoids parsing its private message.
   The later physical before_effect remains EffectRefused. Preserve that distinction
   even when the early callback and final callback reject for the same control.

3. The public enum is already #[non_exhaustive]. An additive variant containing
   only public configured server identity plus a fixed Display category is a
   reasonable API addition. No observer signature, event serialization, caller
   capability or persistence dependency is needed. The dynamic callback error
   must be discarded, not retained as a source or reason. Derived Debug's fixed
   variant name/server field is safe; source() should be None, rather than exposing
   WriterObservationError. Do not rewrite Debug for the entire enum unnecessarily.

4. before_child happens before command/transport construction and actual std
   spawn. A refusal must return without reserving a child worker or touching
   transport state. A canceled awaited callback leaves the existing state unchanged;
   any journal side effect inside that callback is NOT undone or considered a
   closed writer by this classification. NoChild/authority proof is separate.

5. child_started is after actual birth and worker transfer (connection.rs:411ff).
   Its failure currently requests actual settlement before StartFailed. Keep it
   there. Likewise real preparation, stdio conversion, owner availability and
   handshake/timeout retain existing categories/cleanup. No mapping based on text,
   no new WriterOwnershipRefused after birth and no fake NoChild/Closed emitter.
