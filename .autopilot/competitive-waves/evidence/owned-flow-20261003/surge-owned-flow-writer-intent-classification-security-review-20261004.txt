WriterObservationError is an untyped string, so cause cannot safely be split by text. The draft's
explicit callback precision avoids a false claim and preserves early control refusals as this
callback category; final synchronous physical before_effect refusal remains EffectRefused.

Actual connection.rs:339-346 maps before_child failure to fixed StartFailed; ensure_connected
:301-329 consumes restart/backoff state for every error other than EffectRefused. Add the new
variant to the exact no-state-mutation branch and map ONLY that prebirth callback error to it.

roll back before the callback. Preserve exact ConnState/last_exit/attempts/retry deadline and
unhealthy bit. Restart history here means connection restart state; a failed callback may still
have a committed durable intent if reply delivery failed. Do not infer journal absence, no durable
writer obligation, or clean NoChild evidence from this public error. The plan expressly does not
change event/authority semantics; this observation is an implementation invariant, not a new blocker.

mcp_writer_ownership_refused category. No wrapped WriterObservationError/raw journal cause, error
chain or dynamic reason. Existing #[non_exhaustive] McpError accommodates an additive variant without
